# Launch Browser Preview

1. Identify any running dev servers by checking for processes on port 8080
2. If a dev server is running, shut it down by killing the process
3. Start a new dev server with `npm run dev` in the background
4. Wait 3 seconds for the server to initialize
5. Launch a browser preview at `http://localhost:8080`
6. Confirm the browser preview is available for interaction
